# WPS GUI 版权合规调研 —— 能否"全量复刻"？

> 文档编号 **RES-002** · 版本 **v1.0** · 日期 **2026-10-17** · 撰写：许清楚（产品）
> 检索时间：**2026-10-17**（网络资料检索日）· 主要法源检索：中国（CNIPA / 司法案例公开报道）
> 需求来源：用户原话 —— 「**看看 WPS 的 GUI 有没有版权，如果没有做全量复刻**」
>
> ⚠️ **免责声明**：本文为**产品侧合规调研**，**非法律意见**。正式商用前须由执业律师 / 知识产权代理机构出具意见（尤其涉及**外观设计专利 FTO 检索**与**商标申请**）。
> ✅ **立场**：**合规优先**。本文只回答「哪些可以合法借鉴」「哪些绝对不能碰」；**不提供、也不建议任何直接复制他人受保护素材的做法**。

## 0. 结论先行

### 判定：**「不能全量复刻」，但可以有条件地做「功能与布局对标」。**

**三句话概括**：

1. **「WPS 的 GUI 没有版权」这个前提不成立。** WPS 界面上至少存在四层受保护的权益（著作权 / 外观设计专利 / 商标权 / 反不正当竞争法上的"装潢"），且**权利人（金山办公）维权活跃、有胜诉先例**（详见 §1.2 的 GUI 外观设计专利案）。
2. **可以合法借鉴的部分很大。** 功能布局、信息架构、菜单组织、交互范式、快捷键体系——属**「思想 / 功能性设计」**，中国法与主流国际实践基本不给予著作权保护，且是行业通用惯例。
3. **jareking 的合规路线 = 功能对标（已在做）+ 视觉自绘（必须做）+ FTO 检索（上线前必做）。** 图标按 `lucide-react`（ISC/MIT）路线，配色 / 插画 / 启动页 / 字体全部自有或开源授权，不出现任何 WPS 商标 / logo / 品牌识别要素。

### 风险温度计（五层模型）

| 层 | 内容 | 风险 | 结论 |
|---|---|---|---|
| **思想层** | 功能、能力范围、布局思路、交互、快捷键 | 🟢 **极低** | 可自由对标 |
| **结构层** | 菜单组织、Ribbon 分组、面板划分、信息架构 | 🟡 **低-中** | 可对标，但**避免"逐一对应 + 视觉同时一致"** |
| **视觉层** | 图标、插画、字体、配色组合、动效、音效 | 🔴 **高** | **必须自绘 / 自有授权** |
| **标识层** | WPS / 金山 / Kingsoft / 稻壳儿 名称与 logo | ⛔ **禁止** | 任何位置不得使用 |
| **专利层** | 金山 GUI 外观设计专利 | 🔴 **高（已有判赔先例）** | **必须做 FTO 自由实施检索** |

## 1. 法律框架（中国法视角为主）

### 1.1 著作权法

**核心原则：思想 / 表达二分法。**

- 《计算机软件保护条例》**第2条**：计算机软件 = 计算机程序及其有关文档。
- 《计算机软件保护条例》**第6条**：「本条例对软件著作权的保护**不延及**开发软件所用的**思想、处理过程、操作方法或者数学概念**等。」
  → **GUI 的操作方法、功能流程、功能面板的划分，不受软件著作权保护。**

**但界面中的"表达"可以构成作品：**

- **✅ 受保护（表达）**：「微信红包聊天气泡和开启页」案（**北京互联网法院**）—— 认定其"颜色与线条的搭配、比例，图形与文字的排列组合"体现创作者的选择、判断与取舍，具独创性，构成**美术作品**。
- **❌ 不受保护（思想 / 功能性）**：「TV 摇摇乐」案 —— 功能性界面（文字 + 图标按钮）属"计算机操作方法的体现"，**不构成软件著作权保护对象**。
- **实务共识**：任何具**实用性 / 功能性**的因素归入"思想"，不受著作权保护（以划清著作权法与专利法的界限）。
- **折中口径**：功能性表达**若同时达到一定独创性高度**，也可能构成作品（如游戏玩法规则的呈现形式）。

> **结论**：著作权法对 GUI **分而治之** —— 「**怎么排布功能、怎么交互**」= 思想（不保护）；「**具体长什么样**（图标造型、插画、配色与线条的独创性组合、动效画面）」= 表达（可能保护）。

### 1.2 外观设计专利（**本项目最现实的风险**）

- 《专利法》**第2条第4款**：外观设计 = 对产品的整体或局部的**形状、图案或者其结合以及色彩与形状、图案的结合**所作出的富有美感并适于工业应用的新设计。
- **GUI 已明确纳入保护**：
  - **2014 年**《专利审查指南》修改：新增"**包括图形用户界面的产品外观设计**"；
  - **2019 年**指南修改：允许申请人提交**单纯的图形界面**外观设计；
  - **2020 年**《专利法》：确立**局部外观设计**保护。
- **保护期**：外观设计专利权期限 **15 年**，自申请日起算（现行《专利法》第42条，2021-06-01 起施行；此前为 10 年）→ 检索时可据此筛除过期项。

#### ⚠️ 关键判例：「趣键盘」案（**金山办公主动维权并胜诉**）

| 项 | 内容 |
|---|---|
| 原告 | **北京金山办公软件股份有限公司**（WPS 权利人） |
| 被告 | 上海萌家网络科技有限公司（"趣键盘"App） |
| 涉案专利 | 外观设计专利，名称「**用于移动通信终端的图形用户界面**」；专利权人主张保护"设计10" |
| 一审 | **上海知识产权法院** —— 认定被诉界面与专利界面"整体设计和动态变化过程较为近似，不同点不足以对整体视觉效果产生显著影响"，**判赔 25 万元** |
| 二审 | **上海市高级人民法院** —— **维持原判**，认定"被诉侵权图形用户界面落入涉案专利设计10的保护范围" |
| 裁判要点 ① | 比对采用「**整体观察、综合判断**」原则：既看基础界面整体样式，也看**全部动态变化过程** |
| 裁判要点 ② | **「开发并提供软件供用户免费下载」= 实施了该图形用户界面外观设计专利**（软件开发者不能以"我只是做软件、产品是手机"免责） |
| 来源 | 中国法院网《拿什么保护你，我的图形用户界面?》（chinacourt.cn，2023-09）、澎湃新闻、中山市中级人民法院转载（检索 2026-10-17） |

**金山的维权风格佐证**：另有「稻壳儿 / Docer」**商标权 + 不正当竞争**纠纷（金山办公诉知客 / 道客巴巴 / 晟软），一、二审均认定金山在第 9 类"计算机程序"等商品上存在有效商标使用（来源：知产宝 iphouse.cn 判决书，检索 2026-10-17）→ 金山打的是**商标 + 专利 + 反法**的组合拳。

**对 jareking 的直接含义**：

1. 即便 jareking 是**桌面**软件、上述专利是**移动端** GUI，也不能免除风险：
   - 金山可能同样持有**桌面端** GUI 外观设计专利；
   - 2020 年后的「**局部外观设计**」大幅降低了权利人规避难度（可只保护界面中的某个局部）；
   - 侵权比对前提是产品"**相同或相近种类**"（《专利法》第59条 + 最高法相关司法解释；北京高院《专利侵权判定指南（2017）》），**桌面办公软件与 WPS 显然属相近种类**。
2. **必须做 FTO（自由实施）检索**：在 CNIPA 专利检索系统检索申请人含"金山"、"北京金山办公"、"珠海金山办公"的外观设计专利，分类含"界面 / 图形用户界面"，与我们主要界面（Ribbon、启动页、共享/权限面板、版本历史侧栏）逐项比对。

### 1.3 商标法

- 《商标法》**第8条**（商标构成要素：文字、图形、字母、数字、三维标志、颜色组合、声音等）、**第57条**（侵犯注册商标专用权的情形）。
- WPS / 金山办公名下注册商标覆盖**第 9 类（计算机程序）**等；「稻壳儿」案已确认金山在第 9 类有实际有效使用。
- **红线**：不得使用 `WPS`、`金山`、`Kingsoft`、`稻壳儿 / Docer`、WPS 图形 logo，以及**任何近似到可能混淆的标识** —— 覆盖产品名、图标、安装包、官网、文档、宣传物料。
- **与既定的品牌路线一致**：`spec.md` 1.6 已明确「保留 jareking 作为独立产品名，需完成第 9/42 类正式商标检索」（T0.0 任务）。→ 本文结论与之相同：**品牌独立是既定路线，不得动摇**。

### 1.4 反不正当竞争法（"整体像不像"的最后一道网）

- 《反不正当竞争法》**第6条第1项**：擅自使用与他人**有一定影响的**商品名称、包装、**装潢**等相同或者近似的标识，引人误认为是他人商品或者与他人存在特定联系 → 构成混淆行为。
- 《最高人民法院关于适用〈中华人民共和国反不正当竞争法〉若干问题的解释》（**法释〔2022〕9号**）**第4条第1款**：具有一定的市场知名度并具有区别商品来源的显著特征的标识，可认定为第 6 条规定的"有一定影响的"标识。

#### 判例支撑

| 案件 | 要点 |
|---|---|
| **「微信红包」案**（北京互联网法院） | 微信红包相关页面作为服务的**整体形象**，"其中的文字、图案、色彩及其排列组合，具有美化服务的作用" → 属**装潢**；经大量使用可识别服务来源 → 构成「**有一定影响的装潢**」。被告"**将原告页面设计复制后稍加修改即用于自己的软件**" → 构成不正当竞争。判赔 **50 万元 + 合理开支 9.4 万余元** |
| 《炉石传说》诉《卧龙传说》（2014 上海知产十大典型案例） | 全面抄袭画面装潢设计 + 游戏规则 → 构成混淆型不正当竞争 |
| 最高法《北互一周年》官方案例通报 | 著作权法与反不正当竞争法**保护利益不重合，可同时适用** |

> **裁判逻辑的关键**：**「复制 + 略加修改」不能脱责** —— 只要"整体形象（文字 / 图案 / 色彩及其排列组合）"高度近似且可能引发混淆，即可能落入第 6 条。

**对 jareking 的直接含义**：

- 「全量复刻」最现实的风险**不是著作权，而是反法第6条**：即便每个元素各自不构成侵权，**"逐一对应 + 视觉一致"形成的整体印象**仍可能被认定为装潢混淆。
- **但**：反法第6条要求「**有一定影响**」+「**可能导致混淆**」。jareking 作为独立品牌、独立名称、独立图标、独立配色，用户能明确区分产品来源 → **混淆要件难以成立**。
- **「对标布局」与「复制装潢」的分界线就在此**：借"功能与结构"，不借"视觉与整体印象"。

### 1.5 字体（已有专项结论，此处仅衔接）

- 详见 `docs/fonts.md`：内置**只用 OFL**（思源系列 / 霞鹜文楷等，可随包分发）；系统字体（宋体/黑体/楷体/仿宋/微软雅黑）**仅引用、不打包**；**严禁打包方正 / 汉仪 / 微软字体文件**。
- **本文新增红线**：**严禁从 WPS 安装目录提取其界面字体 / 品牌定制字形** —— 提取即复制，属侵权高风险行为。jareking 界面字体用开源方案（思源黑体、Inter 等）。

### 1.6 其他容易被忽视的客体

| 客体 | 保护路径 | 说明 |
|---|---|---|
| 启动图 / 引导页插画 | 著作权（美术作品） | 单张插画独创性高，**几乎必然受保护** |
| 功能图标（图标造型） | 著作权（美术作品）+ 可能的商标 | 整套图标作为"作品集合"；单个图标造型独特亦可主张 |
| 动效素材（Lottie / 序列帧） | 著作权 | **不得录制 / 提取复用** |
| 音效 / 提示音 | 著作权（音乐作品）/ 录音制作者权 | 不得提取复用 |
| 模板素材（稻壳儿模板体系） | 著作权 | 金山已就该体系主张商标权（见 §1.3 案例） |
| 软件代码（含 GUI 实现代码） | 计算机软件著作权 | **反编译、抄代码 = 直接侵权**；本文不涉及任何代码层复用 |

## 2. 可安全借鉴的部分（低风险）+ 理由

| 可借鉴项 | 为何通常不构成侵权 |
|---|---|
| **功能清单与能力边界**（有查找替换、修订、数据透视表…） | 功能属"思想 / 操作方法"；《计算机软件保护条例》第6条明确**不保护"思想、处理过程、操作方法"**；且办公功能是行业通用需求 |
| **信息架构**（模块划分：文字 / 表格 / 演示 / PDF；文档中心与编辑区的关系） | 属**功能性组织方式**，是领域惯例（Word / Excel / PPT / WPS / LibreOffice 同构） |
| **Ribbon / 菜单组织范式** | Ribbon 由 Microsoft 2007 年首创并被全行业采用（WPS、LibreOffice、OnlyOffice 均为 Ribbon 式）→ 已构成 **行业通用设计（de facto standard）**，非任一家的独创表达 |
| **交互范式**（双击重命名、拖拽填充柄、Ctrl+滚轮缩放、右键上下文菜单） | 常用交互惯例；且"降低用户迁移成本"本身是正当竞争利益（`spec.md` 1.1 明确"零成本迁移"是产品目标） |
| **快捷键体系**（Ctrl+S / Ctrl+B / Ctrl+Z、F5 放映、Ctrl+1 单元格格式） | 快捷键绑定是**功能性约定**，被 Office / WPS / LibreOffice 共同使用，属通用知识 |
| **通用 UI 组件形态**（选项卡、侧栏、状态栏、对话框） | 通用组件库形态是**公共领域设计语言** |
| **术语与命令命名**（"另存为"、"查找替换"、"审阅"） | 通用办公术语（中文办公软件共用），非商标性使用 |
| **无障碍 / 可用性规范**（对比度、键盘可达性） | 标准件 |
| **对标差距矩阵本身**（`docs/wps-parity.md` 的做法） | 记录"对方有什么、我缺什么"是行业通行的竞品分析，不涉及素材复制 |

### 可操作的判断标准（一句话）

> **借鉴「做什么」→ 安全；复制「长什么样」→ 危险。**

## 3. 高风险 / 禁止复刻清单

### ⛔ 绝对禁止（一票否决）

1. 使用 `WPS`、`Kingsoft`、`金山`、`稻壳儿 / Docer` 等**文字商标**及其**图形 logo**（任何位置：产品名、图标、安装包、官网、文档、截图水印）。
2. **从 WPS 安装目录提取任何素材**（图标、图片、字体、动效、音效、模板、皮肤）—— 含 `*.ico`、`*.png`、`*.svg`、字体文件、主题包。
3. **反编译 / 抄写 WPS 代码**（含 GUI 布局代码、资源索引、菜单定义表）。
4. **录制 / 截取 WPS 动效**作为素材使用。
5. **复刻启动图 / 引导页插画**（即便重绘，若构图、色彩、元素布局高度相似仍有风险）。
6. **使用 WPS 的品牌配色组合**作为 jareking 主视觉（其金色 / 橙金系 + 特定中性灰构成品牌识别要素的一环，且处于反法第6条"装潢"评价范围）。
7. **用 WPS 界面截图**作为 jareking 的宣传素材。

### 🔴 高风险（须逐项评估）

| # | 项 | 说明 |
|---|---|---|
| 1 | **图标集** | "整体视觉印象近似"的整套图标，尤其是**功能图标一一对应且造型相似** |
| 2 | **局部外观设计专利** | 与金山已授权 GUI 外观设计相同 / 近似的界面 → **必须先做 FTO 检索** |
| 3 | **布局 + 视觉同时高度一致** | Ribbon 标签命名逐一对应 + 图标风格一致 + 配色一致 + 间距 / 圆角一致 → **整体装潢混淆风险（反法第6条）** |
| 4 | **特定独创的界面造型** | 若某面板 / 控件造型有明确独创性表达（非功能必需），不建议照搬 |
| 5 | **专有字体 / 字形** | WPS 界面所用字体文件、其品牌定制字形 |
| 6 | **独有产品文案** | 功能名称通用无碍；**WPS 的独有表述、帮助文本、宣传语不得抄** |

## 4. 竞品对标实践：业界如何"功能对齐而不侵权"

| 关系 | 做法 | 启示 |
|---|---|---|
| **LibreOffice ↔ MS Office** | 全面对标 Office 的功能与格式（.docx/.xlsx/.pptx 兼容），但界面**自有**（Writer/Calc 早期用旧式工具栏，后引入 Ribbon 式 Notebookbar 属**范式借用**），始终使用**自有图标集**（如 Colibre）与自有品牌 | **范式可借、素材自绘、品牌独立** —— 教科书级做法 |
| **WPS ↔ MS Office** | WPS 早期高度对标 Office 的界面与快捷键（"深度兼容"策略），但**2013 年后走自有视觉**（金色系、自有图标、自有动效），Ribbon 分组命名做本地化调整 | **连 WPS 自己都不是"复制式复刻"**，而是"自有视觉 + 范式一致" |
| **OnlyOffice ↔ MS Office** | 功能对齐 + 自有品牌视觉 + 自有图标，协作协议自研 | 同上 |
| **Google Docs ↔ MS Word** | 保留通用交互与快捷键，视觉彻底自有一套（Material） | **用户习惯可迁移，视觉必须独立** |
| **界面专利的反面教材** | 金山「趣键盘」案：被告界面"整体设计与动态变化过程较为近似"即被判侵权 | "对标"与"复制"的司法分界**真实存在且已被判赔**，不能当作安全垫 |

### 归纳出的行业安全模式（jareking 应遵循）

```
功能对齐（✅ 做现成）
  + 交互范式一致（✅ 做）
  + 快捷键兼容（✅ 做）
  + 自有图标（必须自绘 / 许可库）
  + 自有配色与视觉语言（必须）
  + 自有品牌与命名（必须）
  + 法律检索（专利 / 商标 FTO，上线前必做）
```

## 6. 结论

### 6.1 对用户问题的直接回答

> **问：WPS 的 GUI 有没有版权？如果没有做全量复刻。**

**答：前提不成立 —— 「WPS 的 GUI 没有版权」是错的，因此不能全量复刻。**

至少四层保护客观存在：

| 层 | 依据 | 是否已见胜诉先例 |
|---|---|---|
| **著作权** | 图标、插画、动效画面、启动图；界面中具独创性的"色彩与线条的搭配、图形与文字的排列组合"（微信红包案）；软件代码本身 | ✅ 微信红包案（美术作品） |
| **外观设计专利** | GUI 自 2014 年起在中国可获外观设计专利；2020 年确立局部外观设计 | ✅ **趣键盘案（金山诉，一审判赔 25 万，二审维持）** |
| **商标权** | WPS / 金山 / Kingsoft / 稻壳儿 等（第 9 类等） | ✅ 稻壳儿系列案 |
| **反不正当竞争法** | 界面整体形象可构成"有一定影响的装潢"；"复制 + 略改"不能脱责 | ✅ 微信红包案（装潢）、炉石传说案 |

**同时**：「功能布局与交互范式」通常**不受著作权保护**（思想 / 表达二分法 + 《计算机软件保护条例》第6条 + 行业惯例）—— **这正是 jareking 一直在做的对标方式，合法且必要。**

### 6.2 jareking 的正确路线（一句话）

> **功能与布局全量对标（继续做）＋ 视觉与素材 100% 自有（必须做）＋ 法律检索上线前完成（必须做）。**

### 6.3 若坚持"全量复刻"的风险提示（**不建议**）

| 风险 | 后果 |
|---|---|
| 落入 GUI 外观设计专利 | 停止侵权 + 判赔（趣键盘案 25 万量级；桌面端规模化后赔偿更高）+ 产品可能下架 |
| 构成反法第 6 条混淆 | 判赔 + 停止使用相关装潢（**可能被迫大规模重做视觉**） |
| 商标侵权 | 判赔 + 变更产品名 / 标识（品牌资产损失） |
| 著作权侵权 | 判赔 + 删除素材 |
| **叠加效应** | **对个人开发者而言，任何一项都可能超出承受能力；且会直接污染"免费办公软件"的品牌叙事** |

### 6.4 待补充 / 待核验（落地前需闭环）

1. `lucide-react` 当前 **LICENSE 原文**抓取存证（确认 ISC / MIT 的具体范围）。
2. **CNIPA 外观设计专利 FTO 检索**（金山办公名下 GUI 类专利，确认有效期与保护范围）。
3. **商标检索报告**（`spec.md` T0.0，第 9 / 42 类）。
4. **法律口径核验**：GUI 外观设计专利保护期（现行《专利法》第42条）；"相同或相近种类产品"在**桌面软件**场景的司法认定口径（本次调研**未检索到桌面软件领域的直接判例** → 建议律师意见）。
5. 是否需就"界面布局不受著作权保护"取得**律师意见书**作为风控留痕（视商业规模而定，可延后）。
