> 依据：`docs/research-wps-gui-ip.md`（WPS GUI 受著作权 + 外观设计专利 + 商标 + 反法多重保护）。
> 规则：**任何新增视觉素材（图标 / 插画 / 字体 / 动效 / 音效 / 模板）必须在本文件登记**；未登记者不得进仓。

## 2. 禁止清单（红线）

- ❌ 从 WPS / Microsoft Office / 任何第三方软件**安装目录提取**图标、插画、字体、动效、音效、模板；
- ❌ 反编译 / 抄袭他人代码；复制他人启动图插画；
- ❌ 使用 WPS / 金山 / Kingsoft / 稻壳儿 等**商标与图形标识**；
- ❌ 使用他人品牌配色作为 jareking 主视觉；
- ❌ 使用他人产品截图作为宣传素材。
