# jareking 使用说明书

> WPS 平替办公套件 · Writer / Sheet / Presentation / PDF 全格式兼容 + 用户自配 API 的 AI 助手
> 平台：Windows 10 / 11（x64）· 技术栈：Electron + React + TypeScript

本文档面向**使用者与评测者**，说明 jareking 当前已实现的功能与操作方法。开发进度与架构另见 [`docs/spec.md`](spec.md) 与 [`docs/todo.md`](todo.md)。

---

## 1. 快速开始

```bash
# 1) 安装依赖（首次会下载 Electron 二进制，耗时较长）
corepack pnpm install

# 2) 开发模式：先构建 core/ai 包，再启动桌面端
corepack pnpm dev

# 3) 类型检查 / 生产构建
corepack pnpm typecheck
corepack pnpm build
```

启动后主界面顶部为模块切换栏，可在 **文档 / 表格 / 演示 / PDF** 四个工作台之间切换。

> 说明：当前为开发构建版本，通过上述命令在本地运行。后续安装包（.exe）发布配置已就绪，正式发布后会提供一键安装。

## 3. 文字处理 Writer

Writer 是自研文档引擎（TipTap 内核），完整读写 `.docx`，并支持 PDF 导入导出。右侧 **AI 助手面板** 是 Writer 的核心差异化能力。

### 3.1 排版工具箱（离线可用，不消耗 AI）

痛点：空格回车手动排版、缩进/行距不统一、数字可读性差。排版工具箱的所有操作都是**本地确定性执行**——不调用任何 AI、不联网、即时生效，且每一步都可 `Ctrl+Z` 撤销。

| 工具 | 作用 |
| --- | --- |
| **一键整理** | 统一全文：首行缩进 2 字符、1.5 倍行距、两端对齐、清理连续空段 |
| **千分符** | 为全文数字添加千分位分隔符（如 `1234567` → `1,234,567`），提升金额/统计可读性 |
| **套用模板…** | 下拉选择一套标准格式，整篇套用（见 3.1.1） |
| **参考文档格式** | 选一份 `.docx`，自动提取它的正文格式（字体/字号/行距/缩进/对齐）并套用到当前文档 |

> 适用场景：从网上复制粘贴来的杂乱文档、同事发来的不规范稿子，点一下即可标准化。

#### 3.1.1 内置格式模板（四套）

模板同样是本地确定性参数集，离线可用：

1. **政府公文（GB/T 9704 风格）**
   - 标题：二号小标宋、居中
   - 一级标题：三号黑体；二级：三号楷体；三级：三号仿宋加粗
   - 正文：三号仿宋、首行缩进 2 字符、行距固定 28 磅
2. **毕业论文（通用高校规范）**
   - 正文：小四宋体、1.5 倍行距、首行缩进 2 字符；西文 Times New Roman
   - 一级标题：四号黑体
3. **通用报告（日常办公）**
   - 正文：小四宋体、1.5 倍行距、首行缩进 2 字符；标题黑体层级
4. **商务汇报（紧凑现代）**
   - 正文：五号宋体、1.25 倍行距、首行缩进 2 字符；标题微软雅黑加粗层级

> **参考文档格式** 比模板更灵活：当你手头有一份符合单位规范的样本文件，直接用它「克隆」格式，无需手动调参。

### 3.2 AI 自然语言助手

在右侧面板底部的输入框用**自然语言**指挥 AI 修改文档，回车发送。所有文档修改都经由**本地执行器（Executor）确定性落地**，AI 只负责「规划操作」，不会直接拿到你的文档内容乱改。

#### 3.2.1 配置 AI 服务商（首次使用前必做）

jareking 不绑定任何厂商：你自带 API Key，自带 Key **不消耗积分**；Key 经系统加密（DPAPI）存储，明文不落盘。

1. 打开 **设置 → AI 服务商 → 新增**
2. 选择服务商类型：
   - `OpenAI 兼容`（DeepSeek / 通义 / Kimi / 智谱…）
   - `Claude` / `Gemini` / `Ollama（本地）`
3. 填写 **名称 / BaseURL / 模型 / API Key**（BaseURL 已按类型预填，可改）
4. 点 **拉取模型** 自动回填模型列表，或手动填写（如 `deepseek-chat`、`gpt-4o-mini`）
5. 点 **测试连接** 验证可用性，再 **保存**

> 可配置多个服务商，启用其中一个即可。Ollama 本地模型无需 Key。

#### 3.2.2 快捷技能

面板内置一键技能，点击即执行：

- 润色选区 · 续写 · 翻译为英文 · 总结全文 · 插入表格

#### 3.2.3 自由指令示例

- 「把选区加粗」
- 「在文末插入一个 3×3 表格」
- 「加一段对上文的总结」
- 「标题改成红色」
- 「把这段数据做成柱状图」（见 3.3）

执行后面板会显示计划说明与 `✅ N 个操作成功` 的执行摘要。

### 3.3 AI 数据可视化（图表插入）

当你的指令涉及**对比、趋势、占比、统计**，或文中出现成组对比数字时，AI 会优先提取数据并插入图表（自绘 PNG，零额外依赖）。支持三类图表：

- **柱状图 `bar`** · **折线图 `line`** · **饼图 `pie`**

示例指令：「把这段营收数据做成柱状图」「这几个占比用饼图展示一下」。图表以图片形式插入文档，与 `.docx` 一并保存。

## 4. 表格 Sheet

基于 Univer 引擎，兼容 `.xlsx` 读写，支持常见公式与样式。

- **Sheet AI**：在表格内用自然语言下指令（如「找出销售额大于 1000 的行」「把这列求和」），AI 规划操作并经本地执行器落盘。
- 支持从 `.xlsx / .xls / .csv` 导入，导出 `.xlsx`。

---

## 5. 演示 Slides

自研 Canvas 引擎（Konva），支持幻灯片编辑与放映：

- 编辑模式：增删页面、文本框、形状、图片
- **放映模式**：全屏播放、翻页、页码计数、退出（Esc）
- **PPT AI**：用自然语言生成幻灯片（如「做一个 3 页的产品介绍」），AI 规划并生成对应页数。

## 6. PDF

- 内置工具箱：打开 PDF 文件、页面缩略图、基础标注/工具切换
- 与 Writer 互通：PDF 可导入为可编辑文档，编辑后可导出 PDF

## 7. 存储透明（对标 WPS「C 盘不透明」痛点）

打开 **设置 → 存储管理**，可一目了然看到：

- **数据位置**：jareking 所有数据（账户、文档记录、AI 配置）集中保存在一个文件夹
- **当前占用**：实时显示该文件夹大小
- **打开目录**：一键跳转到数据文件夹

承诺：**无云备份副本、无隐藏缓存**。卸载时删除该文件夹即彻底清理，绝不悄悄占用系统盘。

## 8. 账户与积分（商业化预留）

## 9. 常见问题

**Q：AI 助手没反应？**
A：先确认「设置 → AI 服务商」已添加并启用一个配置，且测试连接通过。

**Q：排版工具箱和 AI 指令有什么区别？**
A：工具箱是纯本地规则（整理/千分符/模板/克隆格式），离线即用、零成本；AI 指令用于语义级改写、生成、图表等需要理解意图的任务。

**Q：我的文档数据安全吗？**
A：全部存于本地单一文件夹（见第 7 节），无云端副本。AI 调用时仅把「指令 + 选区/摘要文本」发给你配置的服务商，文档全文不会上传。

**Q：支持 macOS 吗？**
A：当前仅 Windows 10/11（x64）单平台，macOS 暂不在 v1 范围。
