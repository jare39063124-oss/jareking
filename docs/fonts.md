# jareking 字体版权调研与集成方案

> 调研日期：2026-10-14 · 结论可信度：官方渠道/授权协议原文交叉核验
> 目标：jareking 内置「足够多的免费字体」，**零版权风险**（个人开发者无法承担字体索赔）

## 1. 红线清单（严禁触碰）

| 字体 | 风险点 |
|---|---|
| **方正系列** | 仅黑体/书宋/仿宋/楷体 4 款免费，其余（粗黑/兰亭/喵呜等）商用必须授权；**维权最活跃的权利人** |
| **汉仪系列** | 旗黑/尚巍手书等授权费高，电商/海报场景维权高发 |
| **微软雅黑** | Windows 系统自带≠免费商用：屏幕显示可，**印刷/广告/网页嵌入需单独向微软/方正授权** |
| 非官方渠道"免费字体" | 来源不明的下载站是侵权重灾区 |

> 系统字体（宋体/黑体/楷体/仿宋/微软雅黑）jareking **可以列在下拉里引用**（用户机器上已有，调用系统资源不构成分发），但**严禁把字体文件打包进安装包**。

## 2. 推荐内置清单（可随安装包分发，零风险）

### 2.1 OFL 开源（SIL Open Font License 1.1，可商用/修改/随软件分发，需附带协议文本）

| 字体 | 风格定位 | 官方源 |
|---|---|---|
| 思源黑体 Source Han Sans | 正文/界面全能，7 字重，简繁日韩 | github.com/adobe-fonts/source-han-sans |
| 思源宋体 Source Han Serif | 正文/标题宋体，7 字重 | github.com/adobe-fonts/source-han-serif |
| 霞鹜文楷 Lxgw WenKai | 开源楷体标杆，文艺排版 | github.com/lxgw/LxgwWenKai |
| 得意黑 Smiley Sans | 倾斜现代黑体，标题/促销 | github.com/atelier-anchor/smiley-sans |
| 朱雀仿宋 | 仿宋笔意，公文/报告 | github.com/TrionesType/zhuque |
| 抖音美好体 | 品牌标题，书法+现代 | github.com/bytedance/fonts |

OFL 约束（牢记）：① 不得**单独售卖字体文件**（随软件打包 OK）② 分发须附版权声明与 OFL.txt ③ 修改版须改名。

| 京东朗正体/京东榜书体 | 免费商用 | 京东设计中心 |

### 2.3 兜底口径

- 正文双保险：**思源黑体 + 阿里巴巴普惠体**（覆盖日常八成需求）
- jareking 选型原则：**只内置 OFL 字体**（协议统一、可修改、可随包分发、无厂商条款变动风险）；厂商字体 v1 只列在下拉（用户自装后可用），不打包。

## 3. jareking 集成方案（分三步）

| 阶段 | 内容 | 状态 |
|---|---|---|
| ① 引用 | 字体下拉全量列出：系统字体 + OFL + 厂商免费商用（未安装时浏览器 fallback，不影响选择保存——docx 记录字体名，跨机器打开时系统有则显示） | ✅ 本批落地（Writer 字体下拉分组） |
| ② 内置 | 安装包内置 2-4 款 OFL 字体（思源黑体 Regular/Bold + 霞鹜文楷，约 20-40MB），CSS @font-face 注册，附带 OFL.txt；「关于」页附字体版权页 | 待办（T8.4 打包前，控制包体积） |
| ③ 字体管理器 | 设置页「字体」区：扫描 C:\Windows\Fonts + 用户字体目录，列出已装字体与授权提示；一键跳转官方下载缺失的推荐字体 | 待办（P1） |

## 4. 合规动作清单（打包前核查）

- [ ] 内置字体全部来自第 2.1 节 OFL 清单，每款附 OFL.txt + 版权声明
- [ ] 安装包/官网「开源字体鸣谢」页：思源黑体 © Adobe/Google、霞鹜文楷 © 腊八粥（Lxgw）等
- [ ] 不打包任何方正/汉仪/微软字体文件
- [ ] 字体下拉中系统字体组标注「调用系统字体，文件归系统所有」
