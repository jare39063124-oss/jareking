# resources 资源目录（图标占位说明）

本目录用于存放打包所需的平台图标资源。**当前为占位状态，尚未提供任何图标文件**——`electron-builder.yml` 中也因此未配置 `icon` 字段（已在该文件内以注释标注待添加位置）。

## 图标需求

- **源图标**：256x256 以上 PNG（建议 1024x1024），由设计系统（T0.3 设计系统）产出后放入本目录，命名为 `icon.png`
- **Windows（v1 唯一目标平台）**：
  - `icon.ico`：应用窗口/任务栏图标，需包含多尺寸（16 / 24 / 32 / 48 / 64 / 256），由 `icon.png` 转换生成
  - `installerIcon.ico`（可选）：NSIS 安装程序图标，建议 150x57 左右
- **macOS（v1 明确不做，仅备注）**：`icon.icns`，由 1024x1024 源图转换
- **Linux（v1 无计划，仅备注）**：512x512 `icon.png`

## 图标就绪后的配置改动

1. 将设计产出的 PNG 放入本目录并生成各平台图标文件
2. 编辑 `electron-builder.yml`，取消 `win.icon` 等字段的注释并指向对应文件

## 占位期间的影响

不配置 `icon` 时，electron-builder 使用 Electron 默认图标，安装包可正常构建与分发，不影响功能验证。
